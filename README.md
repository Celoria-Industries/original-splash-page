# Celoria Industries — Splash Page

This repository hosts the GitHub Pages splash page for **Celoria Industries**, an AI-First Startup Infrastructure & Investor Governance Platform.

## Live Site Setup (GitHub Pages)

To activate this splash page on GitHub Pages:
1. Navigate to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &gt; **Source**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. The page will be published at `https://john-celoria-ci.github.io/original-splash-page/` (or custom domain `celoria-industries.com`).

## Structure

- `index.html`: Responsive, standalone landing page featuring:
  - Hero: AI-First Startup Operating System vision statement & investor deck request
  - Why Celoria (`#goals`): 6 Core foundation & governance pillars
  - Platform Architecture (`#platform`): Telemetry, compliance guardrails & core code manifesto
  - Execution Plan (`#roadmap`): Three-phase rollout roadmap
  - Investor Inquiries (`#contact`): Contact links (`contact@celoria-industries.com`)
