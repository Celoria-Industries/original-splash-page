# Celoria Industries — Splash Page

This repository hosts the GitHub Pages splash page for **Celoria Industries**, presenting the company's core mission, strategic business goals, software architecture, and development roadmap.

## Live Site Setup (GitHub Pages)

To activate this splash page on GitHub Pages:
1. Navigate to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &gt; **Source**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. The page will be published at `https://john-celoria-ci.github.io/original-splash-page/`.

## Structure

- `index.html`: Responsive, standalone landing page featuring:
  - Hero vision statement
  - Core Business Goals & strategic pillars
  - Software & Architecture overview
  - Three-phase roadmap
  - Contact links (`contact@celoria-industries.com`)
